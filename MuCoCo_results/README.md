# MuCoCo Experiment Results

This section contains results for MuCoCo experiments reported in the main report. Add the MuCoCo experiment results folder under this section like so ```MuCoCo_results/MuCoCo_experiment_results```. The experiment results had to be uploaded separately due to its size. You will need the experiment results to run thes respective notebooks for the various RQs.

This sub-directory structure is as follows:

```markdown
project-root/MuCoCo_results
├── README.md                          # this file
├── MuCoCo_experiment_results          # download the results separately and move the folder here
└── notebooks                          # Python notebooks and scripts for aggregating MuCoCo results
    ├── Appendix_model_confidence_aggregation.ipynb
    ├── Appendix_multiple_mutations.ipynb
    ├── RQ1_BigCodeBench_results_aggregation.py
    ├── RQ1_results_aggregation.ipynb
    ├── RQ2_turbulence_mucoco_aggregation.ipynb
    └── RQ3_mutation_operators_aggregation.ipynb

```

Head to `notebooks` to run notebooks validating MuCoCo results.
